   P2, open — folds into residual 2g in
   `memory/tasks.d/2026-09-26-forced-phi-scrub-verification.md`.

   2g is currently written as "state must not cross a fenced-block boundary in
   a shell variable". The rc=128 case is the same family one level down: a
   value (git's exit status) that does not survive the construct it is written
   in, because an assignment at the end of a `||` list inherits the

   across a boundary — different boundary.

   variable names per block) would NOT catch the rc=128 shape, so if they stay
   one rule the leg needs a second pattern.
