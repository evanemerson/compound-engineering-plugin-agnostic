## Summary

Stage 1 of the OB1 "brain" integration: an **optional, opt-in, cross-repo memory** provider (`cepa:brain`) over a self-hosted [OB1 / Open Brain](https://github.com/NateBJones-Projects/OB1) Agent Memory API. `/cepa:compound` writes each repo's learnings into the brain (producer); `learnings-researcher` recalls them cross-repo (consumer). A lesson learned in one repo now surfaces in another — which also closes the cross-repo "learnings islands" problem (ex-track-#2). Repo files stay source-of-truth; the brain is a regenerable compiled index.

**Ships inert:** no `brain:` key in a repo's `cepa.local.md` → zero behavior change (degrade-to-grep, same pattern as the Phase 7 grounding provider). Safe to merge before the live OB1 instance exists.
