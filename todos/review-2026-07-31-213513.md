# Review Findings — 2026-07-31 21:35 (PR #30)

**Subject:** branch `fix/checker-symlink-traversal-symmetry`, commits `9cdba2d`
and `c2affff` — the `-L`/`-R` traversal symmetry fix and the P1 fix on top of
it.

**Through-line, and it is the sharpest one this line of work has produced:
each fix reintroduced the defect class it was fixing, one layer down.**

- `9cdba2d` fixed "a symlink silently skipped is a file nobody checked" by
  widening leg 4 to `grep -R` — which opens whatever a symlink points at with
  **no file-type check**, so a symlinked device or writerless FIFO blocks it
  forever. Unbounded hang, reachable from any PR branch, on a workflow with no
  timeout.
- `c2affff` fixed that by moving leg 4 to `find -L … -type f`, matching legs
  1-3. But **leg 4 was the only leg that checked its traversal's exit status**
  — `grep -r` returns 2 on an unreadable path and the code tested for it.
  Adopting legs 1-3's idiom adopted their blind spot: an unreadable subtree
  holding an unpinned agent went from `1 MISS` on `main` to
  `0 MISS, 0 WARN — 5 of 5 roots`. That is verbatim the signature of the
  ORIGINAL leg-4 defect this whole branch descends from. Symmetry achieved by
  levelling down.

Two agents reproduced and bisected the second one independently.

The fix that finally generalizes: **one `traverse()` helper every discovery
goes through, reading find's exit status AND stderr, where non-empty stderr is
a MISS.** That is strictly stronger than the loop probe it replaces, and
deleting that probe removed three separate defects with it.

**Verification:** 57 controls, all passing; **30 single-line mutants, 28
caught**, 2 survivors that are provably unpinnable by any fixture (finding 11,
recorded as a limit rather than papered over); checker 0 MISS / 0 WARN; no
fixture leaks. The sweep was re-run on a quiescent tree after an earlier run
was contaminated by concurrent repo writes (finding 12).

- title: Leg 4's rewrite discarded find's exit status and stderr, turning an unreadable subtree from a MISS into a clean pass
- applied_in: "this branch — a traverse() helper every discovery uses, which fails on non-zero exit OR non-empty stderr"

**Problem:** `find` inside a process substitution throws away both its exit
status and its diagnostics. When it can walk only part of a tree it prints
`Permission denied`, skips that branch, exits 1, and returns a **truncated but
non-empty** list. The coverage guard sees a non-empty list; `grep` succeeds
over the survivors; `roots_scanned` increments. Bisected on one fixture:

| checker | verdict |
|---|---|
| `main` | `1 MISS` — `leg 4 grep failed on root 'scripts' (exit 2)` |
| `9cdba2d` | `1 MISS` — same |
| `c2affff` | `-- 0 MISS, 0 WARN --`, exit 0, `across 5 of 5 roots` |

The script's own comment at the `checked` guard names this exact shape: "an
INFO line that counts rows nothing looked at is how a coverage hole reports as
coverage." Legs 1-3 had the same blindness pre-existing; leg 4 was immune only
by accident of using `grep`.

**Fix:** every traversal now goes through `traverse()`. Pinned by controls 33
(unreadable subtree), 35 (cycle under a non-`plugins` root) and 31.

### 2
- status: applied
- severity: P1
- agent: security-sentinel
- category: security
- confidence: 95
- action_class: mechanical
- file: scripts/check-model-pins.sh
- lines: 437, 451 (at 9cdba2d)
- title: `grep -R` blocks forever on a symlinked device or writerless FIFO — an unbounded DoS reachable from any PR branch
- applied_in: "c2affff — leg 4 discovers via find -L … -type f, which resolves the link and tests the target's type"

**Problem:** Reproduced independently twice, with the exact flags and GNU
versions matching `ubuntu-latest`:

```
grep -R  on a symlink to /dev/zero or a writerless FIFO  ->  exit 124 (hung)
grep -r  on the same fixture                             ->  exit 1 (immediate)
find -L … -type f                                        ->  0 files
```

`grep -R` performs no type check before `open()`. Any tracked symlink with a
scannable extension under `plugins/`, `.github/` or `scripts/` triggers it.
The workflow is `on: pull_request`, deliberately unfiltered, and had no
`timeout-minutes` — one file in one branch would hold a runner until the
360-minute default, per push.

**Fix:** `find -L … -type f` resolves the link and tests the TARGET, so a
symlinked regular file is still read — the point of the change — while
devices, FIFOs and sockets are excluded by construction rather than by a
denylist. Plus `timeout-minutes: 10` as a backstop. Pinned by control 32,
which runs under a 20s per-case bound because the regression it guards is a
hang: an unbounded case would hang the suite along with the defect.

### 5
- status: applied
- severity: P2
- agent: silent-failure-hunter, adversarial-reviewer
- category: correctness
- confidence: 95

- lines: 383 (at c2affff)
- title: The loop probe matched one English symptom of a hazard it described generally — three reproduced defects
- applied_in: "this branch — probe deleted; the traverse() stderr rule subsumes it"

**Problem:** `find -L $CITE_ROOTS -type d 2>&1 >/dev/null | grep -i 'loop'`.
The redirection order was correct (verified by both agents). The *predicate*
was wrong, three ways, all reproduced:

1. **Permission errors invisible** — the same mechanism as finding 1, which
   this probe would have caught for free had it not filtered on one word.
2. **ELOOP invisible** — a >40-link chain prints `Too many levels of symbolic
   links`, which contains no `loop`; `loop_warn` stays empty and the subtree
   is silently dropped.
3. **False positive on the word itself** — an unreadable directory whose
   *path* contains `loop` (`plugins/looper`, and note a `ralph-loop` plugin
   exists in this ecosystem) reports "filesystem loop under a scan root" for a
   permission error. Fail-closed, but the diagnostic lies.

Plus the locale dependency the comment disclosed as unavoidable — it was not:
the caller controls the locale.

**Fix:** deleted. `traverse()` treats any non-empty stderr as a MISS, which
covers cycles, ELOOP, permission errors and anything else find learns to say,
in any locale. `export LC_ALL=C` makes the quoted message stable without
detection depending on it. Pinned by controls 31, 33, 35.
