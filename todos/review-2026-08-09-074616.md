- title: The CI templates this repo ships pin a runtime that dies in 38 days, invisible to every detector

**Problem:** `django.yml:77,105` and `astro.yml:21` carry `actions/checkout@v4` —
the last `node20` line per `model-pins.yml`'s own eligibility rule — and
`plugins/cepa/commands/setup.md:178` installs one into a user's project on
`/cepa:setup fix`. GitHub removes Node 20 on **2026-09-16, 38 days out**; after
that they are, in `model-pins.yml`'s words, "a job with no interpreter", and the
breakage lands in the user's repo.

Blind by construction, all four detectors: `runtime-deprecation` reads
annotations from runs *this repo executes*, and templates never execute here;
Dependabot's `github-actions` ecosystem scans `.github/workflows/` and **has no
path form reaching a template directory**; the escape-hatch grep scans
`.github/`; `check-model-pins.sh` checks model pins, not action pins.

This PR is the moment the repo declares action currency solved. It is solved for
the three sites the repo **runs** and unsolved for the two it **ships**.

**Fix:** Bump the tags before 2026-09-16 as its own PR, reading each candidate's
`runs.using` rather than trusting recency. Separately decide who owns template
action currency, since no automation can. Deferred from this PR because a
config-adoption diff is the wrong carrier for a plugin-content change with its
own deadline and its own manifest-bump question.

**Problem:** Nothing ever closes the tracking issue — `grep -rn 'issue close'`

`issues?state=open` queries into one. Deferred — modifies a detector shipped two
