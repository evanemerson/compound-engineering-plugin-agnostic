# Plan review — session roles in cepa

Four personas (sonnet, headless) on the plan. Strong convergence on three
things: the PR-ownership predicate was undefined and, as written, made a
resumed worker block on its own PR; the regex control tested a private copy
instead of the shipped pattern; and U4 granted tools to commands that gained
no step that uses them. The plan is gitignored (`docs/`), so the plan
revision is local-only; this file is the tracked record.

Judgment findings are deferred into the plan's own Deferred / Open Questions
block, each with the decision taken at build.

### 1
status: applied
severity: P1

file: docs/plans/2026-10-05-session-roles.md

title: Ownership predicate undefined; resumed worker blocks on its own PR

**Problem:** §10c said "ownership is the head branch" and §10b said a worker
resumes on the branch already there. A worker that resumed (the handoff case)
did not create that branch, so its own open PR read as non-owned and
overlapping → `blocked: overlaps #N` against itself. Separately, "owned PR
overlaps → existing choice" kept task.md's "Merge PR #N first" option, which
a worker must never see.

**Fix:** §10c defines owned-by-role once: a worker owns only the PR whose
`headRefName` equals the current branch (created or resumed); a worker's
overlap is always `blocked: overlaps #N` and never a merge choice.
