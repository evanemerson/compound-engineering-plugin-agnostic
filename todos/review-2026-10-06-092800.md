# Plan review — worktree-coordinator write guard

Three personas (sonnet, headless). Two things converged: the cited commands'
`allowed-tools` could not run the probe, and the plan's second writable leg
("a branch this run created") was not observable in git. The plan is
gitignored (`docs/`), so its revision is local-only; this file is the tracked
record. Judgment findings are deferred with the decision this worker took at
build, reviewable in the PR.

title: Declared allowed-tools cannot run the §10f probe

**Problem:** triage declares only `git diff`/`git show`; no command declares
`git merge-base`; several lack `git symbolic-ref`. The probe fails closed, so
a coordinator's runs would degrade silently in unattended mode.

**Fix:** U2 adds the probe's verbs to every declaring command; U3 gains a
TOOLS leg that derives the verbs from the shipped block.

**Problem:** the leg lived in the run's memory; a worker started on that

race is a stated limit.
