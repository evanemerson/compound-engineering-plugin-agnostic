# Review — PR #88, dispatch isolation

Eight agents, each dispatched as a reader: no isolation, prompt opening with
§11a's READ-ONLY line and the `<sha>` source line. No P1. Three agents
independently found that `<paths>` was substituted into a single-quoted shell
string with only a prose check in front of it — the adversarial reviewer ran
it and got shell code to execute in report mode — and two found that a path
copied from an agent's text could name another session's live worktree. The
fix, applied here, takes agent ids from the orchestrator's own isolated calls
through a quoted heredoc and builds the path in the block. The adversarial
reviewer also reproduced a commit lost through the worktree's HEAD reflog;
that is a new guard. Live test: this review left no `agent-*` worktree.
